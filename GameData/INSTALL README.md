# INSTALL FOLDERS

Copy the **Caerfinon-KK-World** folder into your GameData File

## Optional Installs

###  KramaxAutoPilot

The folder **KramaxAutoPilot** contains only modified files for flightplans.
It removes the default flightplans so that only ones from the **Caerfinon-KK-World** patches will be loaded
If you do not use this, the new patch will still load the flightplans but you will also have all of the default flightplans that may or may not be present on your world.  
Use only if you have Kramax Auto Pilot installed. Copy the **KramaxAutoPilot** folder into your GameData folder. It will overwrite the flightplan files

 

## Navutilities Updated

The folder **NavInstruments** contains only modified files for runways.
It removes the default runways so that only ones from the **Caerfinon-KK-World** patches will be loaded
If you do not use this, the new patch will still load the runways but you will also have all of the default runways that may or may not be present on your world.
Use only if you have Navutilities Updated installed. Copy the **NavInstruments** folder into your GameData folder. It will overwrite the the runway files
